Brief Background

! The web application was launched in March 2026, so it is still under development and currently serves only static pages.

Hi, I am Bilol Abdilxayev, an Applied Mathematics student at Duke Kunshan University. I decided to share my ideas, conceptual notes, study milestones, and experimental projects, so I created a sort of personal web laboratory.

I switched my intended major mid-career after realizing that I was willing to self-study Software Engineering, and that the quality of my development skills largely depends on hands-on experience rather than only the theoretical knowledge covered in college.

Meanwhile, Computer Science originally emerged as a branch of mathematics, and mathematics is considerably harder to self-study independently. Thus, while still keeping Computer Science in mind, I decided to explore mathematics to build a ground-up understanding of concepts that we often apply as black boxes and take for granted.

I am not trying to discourage anyone from pursuing Computer Science as a college major; this is simply my personal point of view, and it is completely reasonable for others to have different perspectives.

Given this reasoning, you may view this web application as my experimentation environment. The application is hosted on a Duke University managed virtual machine, and the university reserves the right to terminate the server at any time.

The backend is written using the C++ asynchronous services framework, while the frontend currently uses the classic stack of HTML, CSS, and JavaScript.

Features I expect to implement in the near future:

  • Comment sections
  • LaTeX rendering
  • Migration to a proper frontend framework
